# Optimisation workshop

Learning about conflicting objectives, normalisation, and weighting.

Ask your agent how to get started, and what each step is there to teach.

## Steps

1. Building a model is easy while the objectives do not conflict.
2. Objectives can conflict, and the larger reward wins.
3. Weighting is hard when the objectives are not normalised.
4. An analytical normaliser makes the weights easier to tune.
5. An LP maximum gives the same balance without finding the maximum by hand.

## Commands

- `make rooster` shows every task on offer, one row per person.
- `make step1` through `make step5` solve that step and open the roster.
- `make test` runs the tests. A step is finished when its tests pass.
